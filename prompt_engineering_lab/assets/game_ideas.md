# Browser Game Ideas

All games must run by opening one standalone `index.html` file.

1. **Meteor Typing**
   Words fall from the top. Type a word correctly before it reaches the ground.
   Prompt challenges: difficulty curve, score rules, pause/restart, mobile layout.

2. **Memory Grid**
   A sequence of tiles flashes; the player repeats it.
   Prompt challenges: state management, increasing sequence length, clear feedback.

3. **One-Minute Eco Sort**
   Drag or click items into recycle, compost, or trash bins.
   Prompt challenges: data representation, explanations after mistakes, accessibility.

4. **Maze With a Twist**
   Move a character through a grid, but controls rotate every 10 seconds.
   Prompt challenges: precise rules, keyboard handling, win/lose state.

5. **Prompt Detective**
   The game shows two prompts for the same task. The player predicts which will perform better,
   then sees an explanation based on clarity, context, constraints, examples, and output format.
