# Personal Homepage Client Brief

Create a single-file webpage (`index.html`) for **Sam Rivera**, a fictional high-school student.

## Content
- Headline: “Hi, I’m Sam — I build small things that make school life easier.”
- Short bio: Grade 11 student interested in environmental science, photography, and beginner web development.
- Projects:
  1. Cafeteria Waste Tracker — a spreadsheet-based prototype for measuring food waste.
  2. Campus Tree Map — a photo map of notable trees around school.
  3. Study Timer — a minimalist browser timer.
- Skills: HTML/CSS, beginner JavaScript, photography, public speaking.
- Contact button: should open a pre-filled email to `sam.rivera@example.org`.
- Include a short “Currently learning” section.

## Design constraints
- One standalone HTML file with embedded CSS and JavaScript.
- Responsive on phone and desktop.
- Accessible semantic HTML, visible keyboard focus, sufficient contrast, and alt text where relevant.
- No external frameworks or remote images.
- Add one tasteful interaction, such as theme toggle, project filtering, or animated progress indicator.
- The page should still communicate all essential information if JavaScript is disabled.
