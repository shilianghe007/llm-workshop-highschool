# Public-domain song-style reference pack

This pack uses short public-domain reference excerpts and high-level feature notes.
The goal is to learn **style abstraction**, not to copy lines.

## Style A: 19th-century American parlor/folk song
Reference titles: “Oh! Susanna” and “Camptown Races” (Stephen Foster).

Short reference excerpts:
- “Oh! Susanna, oh don't you cry for me”
- “The Camptown ladies sing this song, doo-dah! doo-dah!”

Feature notes:
- Strong repeated refrain.
- Simple, regular meter.
- Concrete travel/place imagery.
- Direct first-person storytelling.
- Catchy nonsense syllables or repeated interjections.
- Verse–chorus structure; easy end rhymes.

## Style B: Traditional sea shanty
Reference titles: “Blow the Man Down” and “Drunken Sailor” (traditional).

Short reference excerpts:
- “Way, hey, blow the man down”
- “What shall we do with a drunken sailor?”

Feature notes:
- Call-and-response structure.
- Short command-like lines.
- Repeated work rhythm.
- Nautical setting and collective “we.”
- Escalating verses with small variations.
- Chorus designed for group participation.

## Student challenge
Write a completely new song about one of these topics:
- debugging code late at night,
- the first day of summer camp,
- losing Wi-Fi during an online game.

Do not reuse any complete reference line. Ask the model to first infer a compact style guide,
then draft, critique against the guide, and revise.
